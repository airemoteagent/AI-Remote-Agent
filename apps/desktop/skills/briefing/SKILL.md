name: briefing
description: Morning briefing — system health, top headlines, saved notes.
---

When asked for a briefing, a summary, or "what's new":
1. Run `sysinfo` (host, uptime, load, memory, disk).
2. Use the `headlines` tool to fetch the top news headlines.
3. Recall memory notes with `memory` (action: recall) for anything relevant.
4. Compose a short briefing: system status line, 3-5 headlines, and any
   relevant remembered notes. Keep it under 200 words and end with the
   single most important thing the user should know today.
