---
name: web-research
description: Multi-source web research with saved notes.
---

When asked to research a topic:
1. Run 2-3 different `web` searches with different phrasings (use action:
   search or ddgSearch-style queries).
2. Fetch the 1-2 most promising pages with `web` (action: fetch) and
   extract the key facts.
3. Cross-check: if sources disagree, say so explicitly.
4. Save a concise note with `memory` (action: remember) so future tasks
   benefit from this research.
5. Answer with a short structured summary: findings, sources, open
   questions. Always distinguish verified facts from assumptions.
