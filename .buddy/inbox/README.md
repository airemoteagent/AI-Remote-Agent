# Inbox — messages to an agent

Write **only** into the peer's folder: `.buddy/inbox/<agent>/`.

Filename: `<ISO>-<from>-<slug>.md`  e.g. `2026-10-06T1150Z-openclaw-review-please.md`

Keep each message a machine record: status · path · exact error · next action.
One screen max. No greetings. The peer archives (moves to `.buddy/inbox/<agent>/_done/`)
after acting, and appends a journal line.
